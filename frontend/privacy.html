PEEXELL Konkurs Bot — Maxfiylik Siyosati (Privacy Policy)

So'nggi yangilanish: 2026-yil 7-sentyabr

PEEXELL Konkurs Bot ("biz", "bizning xizmat") foydalanuvchilarning shaxsiy ma'lumotlari daxlsizligi va maxfiyligini ta'minlashni o'zining eng ustuvor vazifasi deb biladi. Ushbu Maxfiylik Siyosati (Privacy Policy) ilovamiz tomonidan yig'iladigan ma'lumotlar turlari, olib boriladigan ishlov berish jarayonlari, Google OAuth 2.0 hamda YouTube Data API v3 dan foydalanish shartlari va xavfsizlik kafolatlarini batafsil tushuntiradi.

1. Yig'iladigan Ma'lumotlar va Ularning Manbalari

Xizmatimizdan foydalanish jarayonida quyidagi minimal ma'lumotlar to'planishi va qayta ishlanishi mumkin:

  • Telegram Akkaunt Ma'lumotlari: Telegram User ID, ism, familiya hamda foydalanuvchi nomi (@username). Bu ma'lumotlar Telegram WebApp SDK orqali avtomatik olinadi.
  • Telefon Raqami: Telegram bot interfeysi orqali foydalanuvchi tomonidan ixtiyoriy ravishda tasdiqlangan O'zbekiston telefon raqami (+998). Bu ma'lumot konkurs g'oliblarini aniqlash va ular bilan bog'lanish uchun ishlatiladi.
  • Google Akkaunt & YouTube Obuna Ma'lumotlari (Google OAuth 2.0): Foydalanuvchi Google OAuth 2.0 orqali tizimga avtorizatsiya berganida, Google Data API v3 (`youtube.readonly` scope) orqali faqat va faqat foydalanuvchining ko'rsatilgan homiy YouTube kanaliga obuna bo'lganlik (subscription status) holati tekshiriladi. Biz sizning Google parolingiz, elektron pochtangizdagi xatlar yoki boshqa shaxsiy ma me'lumotlaringizga hech qachon kirish imkoniga ega bo'lmaymiz va ularni saqlamaymiz.

2. Ma'lumotlardan Foydalanish Maqsadlari

Yig'ilgan ma'lumotlar faqat quyidagi texnik va huquqiy maqsadlarda ishlatiladi:

  • Konkurs ishtirokchilarini ro'yxatga olish va unikal bilet seriyalarini biriktirish;
  • Sponsor kanallarga (Telegram, YouTube, Instagram) obuna bo me'yorlarini adolatli va 100% rasmiy API orqali tekshirish;
  • Bir foydalanuvchi tomonidan soxta akkauntlar yoki bir nechta Google hisoblari orqali nohalol bilet olish va multi-accounting harakatlarini oldini olish (1 Gmail akkaunt = 1 ishtirokchi bilet);
  • Konkurs taymeri tugaganda g'oliblarni tasodifiy (randomizer) algoritm orqali shaffof aniqlash va mukofotlarni topshirish.

3. Google API Service User Data Policy (Limited Use Requirements)

PEEXELL Konkurs Bot Google API'laridan olingan ma'lumotlarga ishlov berishda Google API Service User Data Policy, jumladan Limited Use (Cheklangan Foydalanish) talablariga 100% to'liq rioya etadi.

"PEEXELL Contest Bot's use and transfer of information received from Google APIs to any other app will adhere to Google API Service User Data Policy, including the Limited Use requirements."

Chetlashlar va Cheklovlar (Limited Use Guarantees):

  • Maqsadli Foydalanish: Google OAuth 2.0 va YouTube Data API v3 (`youtube.readonly`) orqali olingan ma'lumotlar FA QAT foydalanuvchining konkurs homiysi bo'lgan YouTube kanaliga obuna bo'lganligini tasdiqlash uchun ishlatiladi.
  • Uchinchi Shaxslarga Berilmaslik (No Data Sharing/Selling): Google API orqali olingan foydalanuvchi ma me'lumotlari uchinchi shaxslarga, reklama beruvchilarga, ma me'lumotlar brokerlariga yoki boshqa tashqi servisga SOTILMAYDI, BERILMAYDI va ULASHILMAYDI.
  • Reklama Maqsadida Ishlatilmaslik (No Advertising Use): Google foydalanuvchi ma me'lumotlari hech qachon shaxsiylashtirilgan reklamalar (personalized/targeted ads), retargeting yoki tijoriy reklama kampaniyalarida ishlatilmaydi.
  • Inson Tomonidan O'qilmaslik (No Human Reading): Google API orqali olingan ma me'lumotlar insonlar (dasturchilar yoki adminlar) tomonidan o'qilmaydi. Ma me'lumotlar faqat avtomatlashtirilgan koding va API so me'rovlari orqali real vaqt rejimida tekshiriladi.

4. YouTube Data API v3 (`youtube.readonly`) Ishlatilish Tartibi

Google OAuth va YouTube Data API v3 quyidagi qat'iy texnik tartib bo'yicha ishlaydi:

  1. Foydalanuvchi konkurs sahifasidagi "Google bilan kirish va obunani tekshirish" tugmasini bosadi.
  2. Google OAuth 2.0 rasmiy avtorizatsiya oynasi ochiladi va foydalanuvchidan faqat https://www.googleapis.com/auth/youtube.readonly doirasida ruxsat so'raladi.
  3. Tizimimiz Google API endpointidan (subscriptions.list?mine=true) javob oladi va foydalanuvchi homiy YouTube kanaliga obuna bo'lgan bo'lsa, obuna maqomi (true/false) qayd etiladi.
  4. Tekshiruv yakunlangach, avtorizatsiya sessiyasi darhol yopiladi va hechkanday shaxsiy Google kontent saqlanib qolmaydi.

5. Ma'lumotlarni Saqlash va Xavfsizlik Choralar

Biz foydalanuvchi ma me'lumotlarini ruxsatsiz kirish, oshkor bo'lish yoki yo'qotilishidan himoyalash uchun zamonaviy xavfsizlik standartlarini qo'llaymiz:

  • Barcha ma'lumotlar uzatish jarayonlari SSL/TLS (HTTPS) shifrlangan xavfsiz protokollari orqali amalga oshiriladi.
  • Google parollari yoki kirish kalitlari hech qachon serverlarimizda saqlanmaydi.
  • Ma'lumotlar bazasida faqat minimal operatsion ko'rsatkichlar saqlanadi.
